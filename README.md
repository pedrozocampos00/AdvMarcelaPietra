# Site Marcela Piêtra

Landing page institucional para apresentação da advogada Marcela Piêtra, com foco em Direito Imobiliário.

## Estrutura

- `index.html` — conteúdo e estrutura do site
- `style.css` — identidade visual e responsividade
- `script.js` — menu, interações e animações GSAP
- `assets/images/` — imagens otimizadas para web

## Como abrir

Abra o arquivo `index.html` diretamente no navegador ou utilize uma extensão como Live Server no VS Code.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GSAP + ScrollTrigger via CDN
